# Browse Decks deck-selection — Round 22

This update tightens the Browse Decks deck-selection page.

## Changes

- Moved the Review due cards button slightly right and made it larger without moving the Folio wordmark.
- Re-cropped/padded the Review due cards button from the original mockup so the lower border should stop clipping.
- Replaced the Open deck overlay with a safer mockup-derived crop and uses `resizeMode="contain"` so it does not crop inside the selected deck card.
- Removed the "Show cards" / "Hide cards" text from the preview panel. The panel now uses only a small chevron glyph on the right.
- Created horizontal Preview cards panel background PNGs by copying the saved deck carousel shell colors, rotating them sideways, and using them as themed background images.
- The preview panel background now cycles with the selected deck color.
